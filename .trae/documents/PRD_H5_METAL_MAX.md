# 重装机兵H5版 - 产品需求文档

## 1. 产品概述

基于经典FC游戏《重装机兵》(Metal Max)的H5网页版复刻项目。

- **核心目的**：在现代浏览器中重现FC时代经典RPG游戏《重装机兵》的核心玩法，让玩家在手机和电脑上都能体验这款经典游戏
- **目标用户**：怀旧游戏爱好者、RPG游戏玩家、移动端游戏用户
- **市场价值**：填补H5平台经典RPG游戏空白，适配多端设备，提供随时随地的游戏体验

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 玩家 | 赏金猎人 | 控制主角进行探索、战斗、对话 |

### 2.2 功能模块

1. **游戏主界面**：标题画面、开始游戏、继续游戏、设置
2. **世界地图系统**：开放世界探索、NPC交互、触发事件
3. **战斗系统**：回合制战斗、技能释放、道具使用
4. **角色系统**：角色状态、等级经验、装备管理
5. **战车系统**：战车获取、装备改装、性能升级
6. **商店系统**：物品购买、装备出售、道具交易
7. **存档系统**：自动存档、手动存档、云端同步（可选）

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 标题画面 | 标题LOGO | 游戏标题动画、开始/继续/设置按钮 |
| 游戏主界面 | 游戏画布 | Canvas渲染游戏世界、角色、NPC |
| 地图界面 | 瓦片地图 | 16x16像素瓦片组成的RPG地图 |
| 战斗界面 | 战斗场景 | 回合制战斗画面、技能菜单、敌人显示 |
| 菜单界面 | 状态栏 | 角色状态、装备、道具、存档选项 |
| 商店界面 | 商店NPC | 商品列表、购买/出售交互 |
| 设置界面 | 选项卡 | 音量、画质、操作设置 |
| 对话界面 | 文本框 | NPC对话、剧情文本显示 |

## 3. 核心流程

### 3.1 游戏主流程

```
开始游戏 → 创建角色/选择存档 → 进入游戏世界
    ↓
地图探索 ← → 触发战斗 → 战斗胜利 → 获得奖励
    ↓                    ↓
与NPC对话 → 接受任务 → 完成任务 → 获取奖励
    ↓
打开菜单 → 管理装备/道具/存档
    ↓
结束游戏
```

### 3.2 战斗流程

```
遭遇敌人 → 进入战斗 → 玩家回合
    ↓
选择指令（攻击/技能/道具/逃跑）
    ↓
执行动作 → 判定伤害 → 敌人回合
    ↓
敌人AI → 执行动作 → 判定伤害
    ↓
战斗结算 → 胜利/失败/逃跑
```

### 3.3 存档流程

```
打开菜单 → 选择存档 → 显示存档位
    ↓
选择存档位 → 确认覆盖 → 保存数据
    ↓
保存成功 → 返回游戏
```

## 4. 用户界面设计

### 4.1 设计风格

- **整体风格**：复古像素风格 + 现代UI优化
- **色彩方案**：
  - 主色调：#2C3E50（深蓝灰）
  - 次要色：#34495E（浅蓝灰）
  - 强调色：#E74C3C（战斗红）
  - 背景色：#1A252F（深夜蓝）
  - 文字色：#ECF0F1（亮白）
  - 辅助色：#F39C12（金币黄）
- **按钮样式**：像素风格按钮、圆角设计、悬停高亮
- **字体**：
  - 标题：自定义像素字体
  - 正文：等宽像素字体
  - 对话：中文像素字体
- **布局风格**：
  - 游戏画布居中显示
  - 触控按钮覆盖层
  - 响应式缩放适配

### 4.2 页面设计概览

#### 标题画面

| 模块名称 | UI元素 |
|---------|--------|
| 游戏标题 | 像素风格LOGO、发光动画效果 |
| 开始按钮 | 像素风格、闪烁效果、hover放大 |
| 继续按钮 | 存档存在时可用、显示最后游玩时间 |
| 设置按钮 | 音效开关、音乐开关、画质选择 |

#### 游戏主界面

| 模块名称 | UI元素 |
|---------|--------|
| 游戏画布 | 居中显示、保持16:9或自适应、Canvas渲染 |
| 虚拟摇杆 | 左下角半透明、触控显示、拖拽控制 |
| 功能按钮 | 右下角确认/取消按钮、触控友好 |
| 状态栏 | 顶部显示金币、HP、等级 |
| 小地图 | 右上角、当前区域缩略图 |

#### 战斗界面

| 模块名称 | UI元素 |
|---------|--------|
| 战场区域 | 上方显示敌人、下方显示玩家队伍 |
| 命令菜单 | 攻击/技能/道具/逃跑选项 |
| 伤害数字 | 浮动伤害值、暴击特效 |
| 战斗动画 | 像素风攻击动画、特效粒子 |

#### 菜单界面

| 模块名称 | UI元素 |
|---------|--------|
| 角色状态 | 头像、HP条、MP条、等级、经验条 |
| 装备栏 | 装备图标、名称、属性加成 |
| 道具栏 | 物品列表、分类标签、使用按钮 |
| 战车栏 | 战车列表、改装选项、属性显示 |

### 4.3 响应式设计

- **桌面端**：1920x1080基准、全键盘/鼠标操作
- **平板端**：自动适配屏幕、触控+鼠标混合操作
- **手机端**：全屏触控、虚拟摇杆+按钮、优化触摸热区
- **横屏模式**：自动检测并切换布局
- **竖屏模式**：优先适配手机用户

### 4.4 触控优化

- 虚拟摇杆：左下角、60px直径、透明度50%
- 确认按钮：右下角、圆形、确认图标
- 取消按钮：确认按钮左侧、方形、返回图标
- 菜单按钮：顶部导航栏右侧
- 触控热区：最小44x44px符合移动端标准

## 5. 技术可行性

### 5.1 游戏引擎

- **渲染方案**：HTML5 Canvas 2D
- **游戏循环**：requestAnimationFrame (60FPS)
- **输入处理**：统一输入管理系统（键盘+鼠标+触控）

### 5.2 数据存储

- **本地存储**：localStorage/IndexedDB存储存档
- **云端同步**：可选功能、Firebase/LeanCloud

### 5.3 性能优化

- **瓦片系统**：只渲染可视区域瓦片
- **精灵缓存**：预加载常用精灵图
- **对象池**：战斗动画、特效对象复用
- **按需加载**：场景资源按需加载

## 6. 兼容性

### 6.1 浏览器支持

- Chrome 80+
- Firefox 75+
- Safari 13+
- Edge 80+
- 移动端浏览器（iOS Safari、Android Chrome）

### 6.2 设备支持

- 桌面电脑（Windows/macOS/Linux）
- 平板设备（iPad/Android平板）
- 手机设备（iOS/Android）

### 6.3 网络要求

- 首次加载：需要网络下载资源（约50MB）
- 游戏运行：可离线运行（Service Worker缓存）
- 云存档：需要网络同步
